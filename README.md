## Mô phỏng đóng góp mã nguồn mở

Mỗi thành viên phải:
1. Fork repository.
2. Clone repository về máy.
3. Tạo branch riêng.
4. Thêm tên mình vào contributors.md.
5. Commit thay đổi.
6. Push branch lên GitHub.
7. Tạo Pull Request.
8. Review Pull Request của một sinh viên khác.
9. Sửa Pull Request nếu reviewer yêu cầu.
10. Trưởng nhóm thực hiện merge.
